# JJ Elevate — Premium Digital Marketing Agency

A high-performance, responsive web application for **JJ Elevate**, a digital marketing agency specializing in travel, luxury hospitality, and lifestyle brands.

Built with React, Vite, Tailwind CSS, and Framer Motion.

---

## 🌟 Key Features

- **Modern Editorial Aesthetic**: Bespoke agency design with bold typography, high-impact imagery, and subtle micro-interactions.
- **Interactive Capabilities**:
  - Live Interactive ROI & Revenue Potential Calculator.
  - Interactive Consultation Booking Modal with instant step navigation.
  - Smooth page transitions and modular component architecture.
  - Client testimonial carousels and dynamic case study showcases.
- **Responsive Architecture**: Fully responsive across mobile, tablet, and desktop viewports.
- **Production-Ready**: Fast bundle size, optimized assets, and zero-runtime clutter.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v16 or higher) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd "JJ Elevate"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build & Deployment

To generate a production-ready build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
